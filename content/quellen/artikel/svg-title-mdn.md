# title-Element in SVG (MDN)

## Quelle / bibliografische Angaben

MDN Web Docs, englische Fassung.

- Stand laut Seite: „last modified on Jun 6, 2025“
- URL: <https://developer.mozilla.org/en-US/docs/Web/SVG/Reference/Element/title>, abgerufen 2026-10-18 (über Firecrawl)


## Kurzfassung

`<title>` gibt einem SVG oder einem Teil davon einen kurzen zugänglichen Namen.

## Kernaussagen

- Banner: Baseline widely available seit Juli 2015.
- Funktioniert für Container- und Grafikelemente, auch für einzelne Formen innerhalb eines SVG.
- Wird nicht gezeichnet, Browser zeigen ihn meist als Tooltip.
- Gibt es sichtbaren Text, der das Element beschreibt, empfiehlt MDN `aria-labelledby` statt `<title>`.
- Aus Gründen der Kompatibilität mit SVG 1.1 soll `<title>` das erste Kind seines Elternelements sein.
